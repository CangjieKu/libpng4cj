# 兼容性与依赖矩阵

[简体中文](COMPATIBILITY.md) | [English](../COMPATIBILITY_AND_DEPENDENCY_MATRIX.md)

## 能力矩阵

| 范围 | 状态 | 说明 |
| --- | --- | --- |
| PNG 解码 | 已支持 | 非隔行、Adam7、打包行、RGBA8/RGBA16、简化图像缓冲区 |
| PNG 编码 | 已支持 | 非隔行、Adam7、打包行、逐行写入和 sink 输出 |
| 渐进式读取 | 已支持 | 分片输入、暂停/恢复、info/row/end 回调 |
| 读取转换 | 上游源函数 `45/45` | 包含伽马、背景、Alpha、打包、展开、量化和通道转换 |
| 写入转换 | 上游源函数 `5/5` | 包含打包、交换、位移、Alpha、BGR 和单色反转 |
| 标准元数据 | 已支持 | 色彩、显示、文本、时间、校准、调色板、ICC 保留和未知 chunk |
| 简化 API | 已支持 | 内存、文件、流；直接、线性和色表图像缓冲区 |
| C ABI | Preview，`134/258` | 完整验证目前限于 macOS arm64 |

源函数数量描述 `pngrtran.c` 和 `pngwtran.c` 的函数体翻译情况，不等同于
完整 classic API 或 ABI 覆盖率。

## 原生依赖

| 依赖 | 要求 | 用途 |
| --- | --- | --- |
| 仓颉 SDK | `1.0.5` 或更高 | 包最低版本 |
| zlib | 系统开发库 | IDAT 和压缩元数据 |
| C 编译器 | 可选 | 仅 C ABI 消费者需要 |

最终仓颉可执行程序必须链接 `-lz`，即使 libpng4cj 作为 cjpm 静态依赖使用。

## 已验证环境

| 平台 | 工具链 | 已验证范围 |
| --- | --- | --- |
| macOS arm64 | 仓颉 `1.1.3` | doctor、构建、`504/504` 测试、仓颉 consumer、原位置和重定位 C ABI consumer |
| Debian 13 amd64 | 项目维护者提供的原生验证记录 | 构建、`504/504` 测试、仓颉 consumer |

这些记录只证明表中环境和能力，不代表所有操作系统、架构、libc、zlib 或
仓颉工具链组合均已认证。

## 已知边界

- C ABI 还不是完整 `libpng16` 的直接替代品。
- 暂未提供非 macOS 平台的 C ABI 产物和验证记录。
- ICC profile 已解析、校验和保留，但尚未执行 ICC 像素颜色转换。
- 尚未认证超过 100 MB 的图片和并发压力场景。
- zlib 按上游边界保留为外部依赖。
